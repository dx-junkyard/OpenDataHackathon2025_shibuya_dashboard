# 政策別の現状と主要課題まとめ（要約）

第 3 回検討委員会資料と委員の意見をまとめた資料で、次期計画の「現状と主要な課題」はここから要約・抜粋する想定（PDF 2 頁）。

<!-- page: 2 -->

## 政策 1 子育て支援: 区の現状（PDF 3 頁）

<!-- page: 3 -->
- 世帯の小規模化や共働き世帯の増加で、妊娠期から子育て期の支援ニーズが多様化している。
- 周囲に頼れる人がおらず、相談したくても相談できる人がいないまま育児を続ける家庭がある。
- 家庭環境や発達上の課題が複合化するケースの増加が見込まれ、関係機関が連携した継続支援が重要になる。
- 子育て家庭が地域と日常的に関わる機会を得にくく、地域との関係が希薄になりやすい。

## 政策 1 子育て支援: 主要な課題（PDF 3 頁）

- 保育ニーズの変化を把握し、待機児童が発生しない状態を安定的に維持する。
- 妊娠期から子育て期まで継続して家庭と関わり、状況に応じた相談・支援を行う。
- 保護者が必要な支援を適切な時期に利用できるよう、分かりやすい情報提供と丁寧な相談対応を続ける。
- 不安や悩みを身近に相談できる環境の整備、子育てネウボラの拡充と関係機関の連携。
- ファミリー・サポート・センターや子育て支援センターによる、地域で子育て家庭を支える仕組みの充実。
- 子育て世帯の孤立を防ぐ。

## 政策 1 子育て支援: 検討委員会の意見（PDF 4 頁、要点）

<!-- page: 4 -->
- 相談環境の整備と、相談につながらない家庭への対応は区別すべき（必要性を自覚していない、行政への抵抗感、多忙、言語・文化の障壁）。ニーズの詳細把握やアウトリーチ型の支援も方向性として示す必要があるのでは。
- 区の現状として、転入・転出の多さ、共働き世帯の多さ、外国人・多文化家庭、地域との関係が薄い家庭、デジタルに慣れた世帯と対面支援が必要な世帯の併存などを整理したうえで課題を設定するとよいのでは。
- 施設や窓口を増やすより、既存施設間の情報連携、オンライン相談、保育需要予測、民間・NPO への委託、地域資源のコーディネートを組み合わせる方が持続可能では。
