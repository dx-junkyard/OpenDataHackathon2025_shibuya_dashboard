# 長期基本計画2017-2026 最終評価結果概要（要約）

## 評価の方法（PDF 2〜3 頁）

<!-- page: 2 -->
- 計画期間の終了に合わせ、施策の柱ごとに成果指標の達成状況と取組成果・課題をまとめ、次期計画の策定に反映する。

<!-- page: 3 -->
- 達成率 =（最新実績値 − 基準値）÷（目標値 − 基準値）× 100。
- 判定は S（令和7年度時点で最終目標値を達成）、A（80%以上100%未満）、B（60%以上80%未満）、C（60%未満）、E（指標変更や実績不明で評価困難）の 5 段階。

## 全体と分野別の達成状況（PDF 4 頁）

<!-- page: 4 -->
- 全体では約36%が最終目標値を達成済み、約11%が達成率80%以上、約34%が達成率60%未満で目標達成は困難な状況。
- C 健康・スポーツ、D 防災・安全・環境・エネルギー、F 文化・エンタテイメントの各分野は、50%以上が目標値を達成できる見込み。
- 分野 A（子育て・教育・生涯学習）の内訳は図のみで、この要約には含めていない。
